# 发布到腾讯云 COS(家人免代理直接访问)

本网站是纯静态站点(`out/` 文件夹),发布到腾讯云对象存储 COS 后,家人**不用代理、不用备案**,直接用链接就能打开。一年花费约 1 元。

---

## 第一步:注册腾讯云并实名认证(约 10 分钟,一次性)

1. 打开 <https://cloud.tencent.com> ,点击右上角「注册」
2. 用手机号注册,按提示完成**实名认证**(个人认证:手机号 + 身份证,免费)
3. 进入控制台: <https://console.cloud.tencent.com/cos>

## 第二步:创建存储桶(约 3 分钟)

1. 在 COS 控制台点击「创建存储桶」
2. 填写:
   - **名称**:小写英文+数字,例如 `shushuyu-site`(全腾讯云唯一,可自定义)
   - **所属地域**:选离家人最近的,如广州 `ap-guangzhou`、上海 `ap-shanghai`、北京 `ap-beijing`
   - **访问权限**:必须选「**公有读私有写**」
   - 其余默认,点击「创建」
3. 创建后记下存储桶名字和地域,后面要用

## 第三步:开启静态网站托管(约 2 分钟)

1. 点进刚创建的存储桶 → 左侧菜单「**基础配置**」→ 找到「**静态网站**」→ 点「编辑」开启
2. **索引文档**填:`index.html`
3. **错误文档**填:`404.html`
4. 保存。开启后页面顶部会显示**静态网站访问域名**,例如:

   ```
   https://shushuyu-site-1250000000.cos-website.ap-guangzhou.myqcloud.com
   ```

## 第四步:上传网站文件(约 5 分钟)

1. 先构建最新版网站(在项目目录运行):
   ```bash
   npm run build
   ```
   生成的文件在 `out/` 文件夹(已生成好,内容最新)

2. 下载腾讯云 COS 桌面客户端 **COSBrowser**:
   <https://cosbrowser.cloud.tencent.com>

3. 打开 COSBrowser → 用腾讯云账号登录 → 找到刚才的存储桶

4. 把 **`out/` 文件夹里的内容**(注意是里面的全部内容,不是把 out 文件夹整个拖进去——要让 `index.html` 位于存储桶根目录)全部拖进存储桶

## 第五步:发给家人 🎉

把第三步记下的静态网站访问域名发到家庭群里,家人点开就能看到网站了。

- 手机、电脑、平板都能打开,不用装任何软件
- 每次更新内容后,重新 `npm run build`,再把 `out/` 里**有变化的部分**(或直接全量覆盖)重新拖上去即可

## 可选:配置 GitHub 自动发布(以后不用手动上传)

1. 把项目推到 GitHub 仓库
2. 在 GitHub 仓库页面 → Settings → Secrets and variables → Actions → 新建 4 个密钥:

| 密钥名 | 值 |
|---|---|
| `COS_SECRET_ID` | 腾讯云 API 密钥 ID |
| `COS_SECRET_KEY` | 腾讯云 API 密钥 Key |
| `COS_BUCKET` | 存储桶名,如 `shushuyu-site-1250000000` |
| `COS_REGION` | 地域,如 `ap-guangzhou` |

> API 密钥在 <https://console.cloud.tencent.com/cam/capi> 创建(子账号密钥更安全)

3. 项目里已附好工作流文件 [`.github/workflows/deploy-cos.yml`](../.github/workflows/deploy-cos.yml),以后每次 `git push` 到 `main` 分支,网站会自动构建并上传,无需手动操作

## 常见问题

- **打开显示 403 / 无权限**:检查存储桶「访问权限」是否为「公有读私有写」
- **打开是乱码/下载文件**:检查是否用了「静态网站访问域名」(`cos-website` 那个),而不是默认 API 域名
- **想用自己买的域名**:需要先备案(ICP),再把域名解析到 COS 并配置 CDN,详见腾讯云文档
